    Overview

    Key Formulas
    
                    
    
                        Production Risk Score = CVSS×0.25 + Criticality×0.25 + Impact×0.20 + Exploitability×0.10 + Aging×0.10 + Exposure×0.10
                        Detection Confidence = (Tools that detected CVE ÷ Total tools compared) × 100
                        MTTR = SUM(Resolution Days) ÷ COUNT(Closed Tickets)
                        SLA Breach % = Breached Incidents ÷ Total Incidents × 100
                        Hours Saved = (Incidents × Manual min − Incidents × Processing min) ÷ 60
                        FTE Savings = Hours Saved × 12 ÷ (160 × 12) → Cost Avoidance = FTE × Annual Analyst Cost

    Client Data Layer
    
                    
    SwimlaneAPI (api.js) — wraps the Swimlane REST API. Every method returns { data, source } where source is "live" or "mock"; it automatically falls back to a deterministic mock incident pool if USE_LIVE is off, credentials are missing, or the request fails/times out.
    
                    
    Reports (reports.js) — parses an imported CSV, classifies each row into category/severity/automation via regex rules, and produces the same aggregate shape the charts expect.
    
                    
    INTEGRATIONS (integrations.js) — stores vendor credentials in encrypted backend storage; the browser receives safe status metadata only. GitHub, GitLab, MISP, Keycloak, OpenSearch, Wazuh Indexer, SentinelOne, Defender for Cloud Apps, Prisma Cloud, and NetApp ONTAP have manual read-only API sync; most other vendor cards remain settings-only.
    
                
    

                
    
                    
    Integrations
    
                    
    29 tools are configurable under Settings - Integrations. Eleven read-only API feeds can be synced manually from the SIEM Workbench; the remaining vendor cards are settings-only or require a provider-specific API contract. Hide/search/filter controls only change this browser's view; they do not clear credentials. Rubrik/Cato events can use the local webhook receiver. Cato events sync read-only; DC2Cloud appears in Zero Trust readiness, but live telemetry and policy enforcement remain disconnected until its connector is implemented and tested.
    
                
    

                
    
                    
    Production Risk Intelligence
    
                    
    Under Risk Management: an executive risk view, a CVE detection correlation matrix (Claroty vs Nessus/BMC/Trellix/CrowdStrike/PITS), MTTR & SLA analytics, a plant × production-line risk heatmap, and a status grid for all 11 OT/IT security tools (Claroty, Swimlane, CrowdStrike, Defender, Azure, Wiz, Sentinel, Nessus, Trellix, BMC, PITS).
    
                
    

                
    
                    
    Troubleshooting
    
                    
    
                        
    SymptomFix
    
                        
                            
    Blank charts on a tabChart.js needs a visible canvas — charts render/resize on first tab activation; switch tabs once
    
                            
    Claroty live data not loadingOpen Settings - Integrations and confirm Claroty credentials are configured on this backend.
    
                            
    Import failsEnsure the CSV has Tracking Id, Case Status, BMC Incident Title columns
    
                            
    Public feeds show errorsRequires outbound internet access to CISA/NVD/MSRC/URLhaus; failures are caught per-source and shown individually
    
                            
    Port already in useStop the other process on 8080 or edit PORT in server.py

# Project Test Dashboard Copies

This folder contains copies of the dashboard implementation grouped by requested area.

- `overview/dashboard.html` - Overview page copy
- `vulnerabilities/dashboard.html` - Vulnerabilities page copy
- `riskmanagement-cab/dashboard.html` - Risk Management / CAB page copy
- `secumat/dashboard.html` - SECUMAT page copy
- `compliance/dashboard.html` - Compliance page copy
- `shared/` - Shared Flask app, template, static assets, automation, ETL, and SQL dependencies

The five pages are sections of the shared dashboard application, so the feature copies use the same shared API and runtime files in `shared/`.
